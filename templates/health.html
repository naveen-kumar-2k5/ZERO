API Health

Live status of every service in the ZeroRespond pipeline: webhook, UI, database, and poller.

Checking services…
Running health checks against all four components.
What each check means

Webhook API — the endpoint Wazuh posts detections to, on port :5000. If this is down, no new detections arrive.

UI / Flask app — this server, on port :5001. If this is down, you're reading a cached page.

PostgreSQL — the alerts table on zerorespong_db. Reports row count and newest row age. If this is down, nothing can be read or written.

Wazuh poller — no HTTP endpoint; health means "rows are still being written". If the newest row in alerts is older than 5 minutes, the poller is stale (paused, crashed, or the webhook URL is wrong).
